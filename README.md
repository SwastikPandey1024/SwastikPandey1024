### 📈 SalesPulse AI

An ML-powered **sales forecasting platform** built around real-world business data.

**Highlights**

* XGBoost-based forecasting
* 9,994 Superstore records
* 13 engineered features
* Lag & rolling-window features
* Model comparison against Linear Regression and Random Forest
* Scikit-learn preprocessing pipeline
* Joblib model serialization
* 7-day iterative forecasting
* Streamlit deployment
* Batch CSV prediction
* KPI & feature-importance visualisation

**Stack:** `Python` `Pandas` `Scikit-learn` `XGBoost` `Streamlit`

### 📊 Stock Sentiment Analysis

A large-scale NLP project analyzing **108,750 stock-related tweets**.

**Pipeline**

```text
Raw Tweets
    ↓
Cleaning & Tokenisation
    ↓
NER / Financial Entity Extraction
    ↓
VADER Sentiment
    ↓
TF-IDF Representation
    ↓
Logistic Regression / Random Forest
    ↓
Market Sentiment Insights
```

**Result:** Random Forest reached approximately **78% accuracy** and **80% F1-score**.

**Stack:** `Python` `spaCy` `NLTK` `VADER` `TF-IDF` `Scikit-learn`
